# هسته عامل خودمختار

این پوشه هسته عامل مهندسی نرم‌افزار خودمختار را نگهداری می‌کند.

## وظیفه عامل

عامل یک درخواست فارسی دریافت می‌کند، پروژه را بررسی می‌کند، فایل‌های لازم را می‌سازد یا اصلاح می‌کند، تست و Build را اجرا می‌کند و در صورت خطا وارد دور اصلاح بعدی می‌شود.

## مسیرهای دریافت دستور

1. اجرای دستی Workflow در GitHub Actions
2. Issue با عنوانی که با `[Agent]` شروع شود
3. در آینده دریافت دستور از `AI-Agent-Manager` از طریق `repository_dispatch`

## خروجی

برای پروژه‌های وب، عامل فایل‌های قابل انتشار را داخل `site/` قرار می‌دهد. Workflow می‌تواند این پوشه را به‌عنوان سایت GitHub Pages منتشر کند.

تمام توضیحات و کامنت‌های پروژه فارسی هستند.
