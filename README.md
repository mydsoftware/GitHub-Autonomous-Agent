# عامل خودمختار گیت‌هاب

عامل مهندسی نرم‌افزار خودمختار که مستقیماً روی GitHub Actions اجرا می‌شود.

## هدف

تو فقط یک دستور نرم‌افزاری می‌دهی؛ عامل درخواست را تحلیل می‌کند، فایل‌های لازم را می‌سازد یا اصلاح می‌کند، تست و Build را اجرا می‌کند، خطاها را بررسی می‌کند و تا رسیدن به نتیجه یا پایان سقف تلاش ادامه می‌دهد.

## روش استفاده

### روش اول: اجرای مستقیم از GitHub

در مخزن به مسیر **Actions → اجرای عامل خودمختار → Run workflow** برو و دستور فارسی را در ورودی `task` بنویس.

نمونه:

```text
یک سایت فارسی و مدرن با موضوع ماهواره مرکزی بساز. ریسپانسیو باشد و صفحه اصلی، درباره ما، خدمات و تماس با ما داشته باشد.
```

### روش دوم: اجرای عامل از طریق Issue

یک Issue بساز و برچسب `agent` را به آن اضافه کن. عنوان و متن Issue به‌عنوان دستور عامل در نظر گرفته می‌شود.

## موتور هوش مصنوعی

عامل در GitHub Actions از **GitHub Models** برای استنتاج استفاده می‌کند و احراز هویت مدل با `GITHUB_TOKEN` انجام می‌شود.

مدل پیش‌فرض فعلی:

```text
openai/gpt-4.1
```

مدل از طریق متغیر `AI_MODEL` قابل تغییر است.

## حلقه خودمختار

```text
دستور کاربر
    ↓
تحلیل توسط مدل
    ↓
ساخت یا اصلاح فایل‌ها
    ↓
اجرای تست / Build
    ↓
بررسی نتیجه
    ↓
اصلاح خودکار در صورت خطا
    ↓
تکرار تا موفقیت
    ↓
Commit و Push
    ↓
گزارش نتیجه
```

## محدودیت‌های ایمنی فعلی

- مدل اجازه نوشتن فایل خارج از پوشه پروژه را ندارد.
- دستورهای اجرایی فقط از مجموعه ابزارهای توسعه و تست مجاز هستند.
- اطلاعات محرمانه نباید در کد یا خروجی مدل قرار بگیرند.
- سقف اجرای حلقه روی ۸ دور تنظیم شده است.
- `GITHUB_TOKEN` فقط با مجوزهای لازم Workflow استفاده می‌شود.

## ساختار

```text
.github/workflows/agent.yml   ← اجرای عامل در GitHub Actions
agent/github_model.py         ← اتصال به GitHub Models
agent/runner.py               ← موتور اجرای خودمختار
agent/loop.py                 ← حلقه مهندسی
agent/config.py               ← تنظیمات
requirements.txt              ← وابستگی‌ها
```

## وضعیت

**هسته اجرای واقعی عامل راه‌اندازی شده است.**

مرحله بعدی، تست عملی با یک درخواست واقعی، سپس اضافه‌کردن قابلیت‌های پیشرفته مانند ساخت Pull Request، انتشار خودکار سایت، مدیریت چند پروژه و اتصال به `AI-Agent-Manager` است.
